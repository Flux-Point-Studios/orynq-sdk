Add the Windows host package for the orynq credential broker (spec §16). `orynq-pipe-frontend`, a Rust sidecar, owns the named pipe: first instance only, remote clients rejected, an owner-pinned DACL that grants admitted accounts no pipe-instance creation, caller identity taken by impersonating the client at identification level (SID, logon LUID, TS session, integrity RID), 1 B to 16 MiB frames, one request in flight, an idle close (300 s by default, 1 s to a day) and 32 connections per peer. It hands `{connId, peer, frame}` to Node over stdio and never parses a frame. `spawnPipeFrontend`, also exported alone at `./frontend` so a caller loads no native code, spawns it with the broker-wire stdio mux on its stdin and stdout for the broker to serve, and refuses a non-local pipe, an admitted SID that is not a user or service account, or an idle period outside that range before spawning; `connectBroker` connects at identification level with exactly the rights the frontend grants and refuses a pipe its pinned service account does not own. `sealSecret`/`unsealSecret` wrap the sealed executor's identity under a non-exportable TPM key in the calling account's Platform Crypto Provider store. `orynq-service-host` runs a program as a Windows service under its virtual account, and `scripts/install-service.ps1` installs one with an admin-only service DACL, recovery actions and a state directory admitting only SYSTEM and the service SID.
