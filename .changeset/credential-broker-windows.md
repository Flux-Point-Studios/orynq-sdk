Add the Windows host package for the orynq credential broker (spec §16). `orynq-pipe-frontend`, a Rust sidecar, owns the named pipe: first instance only, remote clients rejected, an owner-pinned DACL that grants admitted accounts no pipe-instance creation, caller identity taken by impersonating the client at identification level (SID, logon LUID, TS session, integrity RID), 1 B to 16 MiB frames, one request in flight, a 300 s idle close and 32 connections per peer. It hands `{connId, peer, frame}` to Node over stdio and never parses a frame. `startFrontend` runs it from Node; `connectBroker` connects at identification level with exactly the rights the frontend grants and refuses a pipe its pinned service account does not own. `sealSecret`/`unsealSecret` wrap the sealed executor's identity under a non-exportable TPM key in the calling account's Platform Crypto Provider store. `orynq-service-host` runs a program as a Windows service under its virtual account, and `scripts/install-service.ps1` installs one with an admin-only service DACL, recovery actions and a state directory admitting only SYSTEM and the service SID.
